## 🧠 Project Overview  

**Smart Email AI Assistant** is a full-stack web application that uses **Spring Boot**, **Spring AI**, and **React.js** to generate intelligent, human-like email content automatically.  
It helps users write professional, personalized, and time-efficient emails — powered by AI.  

---

## ⚙️ Tech Stack  

| Layer | Technologies Used |
|-------|--------------------|
| **Backend** | Spring Boot, Spring AI, Maven |
| **Frontend** | React.js, Vite, JavaScript, HTML, CSS |
| **Extension** | Chrome Extension |
| **Language** | Java 21, Node.js 20+ |
| **Version Control** | Git & GitHub |

## 🧩 Installation & Setup  
### 1️⃣ Clone the repository  
```bash
git clone https://github.com/DivyaMandewal73/Smart_Email_AI.git
cd Smart_Email_AI

2️⃣ Backend Setup (Spring Boot)
--> cd Backend
--> mvn clean install
--> mvn spring-boot:run

3️⃣ Frontend Setup (React)
--> cd Frontend
--> npm install
--> npm run dev

4️⃣ Chrome Extension Setup

--> Open Chrome → go to chrome://extensions/

--> Enable Developer mode

--> Click Load unpacked → select the Extension folder
